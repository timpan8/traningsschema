# Träningsschema

Personligt träningsschema för tisdag–torsdag med avbockning per vecka.

[Öppna sidan](https://timpan8.github.io/traningsschema/)

Varje övning har en guide med bild av utrustningen, tre steg och en pausbar demonstration utan ljud. Alternativa utföranden väljs i guiden. Plankan visas med en stillbild. Avbockningar sparas i webbläsarens localStorage, per enhet och vecka.

Sidan är statisk och publiceras från `main` via GitHub Pages. `guides.js` innehåller övningskopplingar, instruktioner och källor. `guide-ui.js` hanterar guiderna och `media/` innehåller optimerade filmer och bilder. Se [MEDIA-SOURCES.md](MEDIA-SOURCES.md) för källor och villkor; medierna används för detta icke-kommersiella projekt med hänvisning till StrengthLog.

Verifierat i Chromium: alla 23 övningsrader, 32 unika demonstrationer inklusive varianter, uppspelning, stängning med Escape, återställt fokus, sparade avbockningar samt mobilbredder 320 och 390 px.
